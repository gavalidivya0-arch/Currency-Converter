# Currency Converter

A modern, responsive, and visually stunning Currency Dashboard built entirely with Vanilla web technologies. It features a complete financial interface layout, data visualization via Chart.js, and a sleek minimalist aesthetic.

## 🚀 Features

- **Modern Grid Layout**: A fully responsive sidebar and dashboard layout built using CSS Grid and Flexbox.
- **Data Visualization**: Integrated with [Chart.js](https://www.chartjs.org/) for beautiful, interactive bezier-curve line charts and donut charts.
- **Premium Aesthetics**: Pure white components overlapping a light-blue tinted background, featuring smooth micro-interactions.
- **Custom Iconography**: Styled with [Phosphor Icons](https://phosphoricons.com/) to maintain a highly professional look.
- **Zero Frameworks**: Built strictly with HTML5, CSS3, and Vanilla JavaScript.

## 🛠️ Tech Stack

- **HTML5**: Semantic and accessible structure.
- **CSS3**: Custom variables, Grid/Flexbox layouts, hover states, and animations.
- **Vanilla JavaScript**: Used for initializing and customizing the Chart.js graphs.
- **Chart.js**: Utilized for rendering the Statistics (Line Chart) and Balance Details (Donut Chart).

## 📂 Project Structure

```text
.
├── index.html       # The main dashboard layout and structure
├── style.css        # All styling, variables, and animations
├── script.js        # Chart.js initialization and config
└── README.md        # Project documentation
```

## 💻 Getting Started

To run the project locally, you don't need any build steps, bundlers, or package managers! 

1. Clone this repository.
2. Open `index.html` in your favorite web browser. 
   *(Alternatively, use an extension like VS Code "Live Server" for hot-reloading).*
